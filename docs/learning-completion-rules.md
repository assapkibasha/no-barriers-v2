# Approved learning rules

Confirmed by the user on 14 October 2026.

- A lesson such as Numbers contains multiple required sign animations and associated questions.
- Completion requires finishing all required animations and correctly answering every required question.
- Learners may retry until they succeed.
- Each lesson attempt starts with five hearts. Each incorrect submitted answer costs one heart.
- At zero hearts, learners review the signs they missed before hearts are restored for another attempt. There is no timed waiting requirement.
- Previously completed work stays saved through review and retries.
- Correct answers earn experience points and contribute to a run of correct answers. Exact point values and bonus rules are not yet specified.

Implementation details still to define: animation completion detection, review completion detection, point values, and correct-answer streak reset rules. Daily attendance streaks have not been specified.

These are approved product requirements; this document does not imply that the backend, animation playback, or hearts system has been implemented.
